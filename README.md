# Sistema de Apuração de Votos

Projeto desenvolvido em linguagem C como atividade acadêmica da graduação em Engenharia de Software.

## Sobre o projeto

O sistema realiza a apuração de votos, permitindo registrar os votos recebidos pelos candidatos e calcular os resultados da votação.

## Tecnologias utilizadas

- Linguagem C
- Dev-C++

## Arquivo principal

- `atividade_votacao.c`

## Objetivo

Praticar conceitos fundamentais de programação, como matrizes, estruturas de repetição, variáveis e operações matemáticas.

---

Desenvolvido como projeto acadêmico.
